# /pr

Makes sure the work is committed and on a branch, then opens or updates the PR with a description a reviewer can actually use.

Read `.agents/skills/pr.md` and follow it. That file is the source of truth, shared with
every other agent in this repo. If the behaviour needs to change, edit it there, not here.
