# /commit

Groups the pending changes by what they accomplish, writes a short human commit message for each, and pushes after every commit.

Read `.agents/skills/commit.md` and follow it. That file is the source of truth, shared with
every other agent in this repo. If the behaviour needs to change, edit it there, not here.
